### Changes Implemented
- Built `scripts/website_analysis/ads_transparency.py`: an on-demand check of Google's own Ads Transparency Centre via its keyless internal RPC (`SearchService/SearchSuggestions` resolves a domain/brand to advertiser IDs; `SearchService/SearchCreatives` lists creatives with format and first/last-shown dates, paginated by cursor). Credentials are read at request time only, used for the request, never cached or logged.
